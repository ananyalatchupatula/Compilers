# Makefile Guide - New Refactored Compiler

## Overview

The new `Makefile` is specifically designed to compile and test the refactored SCLP compiler with the new class-based AST hierarchy.

**Key Differences from Old Makefile:**
- Uses `parser_new.y` instead of `parser.y`
- Uses `ast_new.cpp` instead of `ast.cpp`
- Removes old `tac.cpp` dependency
- Adds comprehensive testing targets
- Includes helpful status and help commands

---

## Quick Start

### Compile the Compiler
```bash
make
```

### Run Tests
```bash
make test
```

### Test Single File
```bash
make test-one TEST=test_case_1.c
```

### Clean Up
```bash
make clean
```

## All Available Commands

### Build Commands

| Command | Purpose |
|---------|---------|
| `make` or `make all` | Compile the compiler |
| `make clean` | Remove compiled object files |
| `make clean-all` | Remove all generated files |
| `make clean-tests` | Remove test output files |
| `make status` | Show compilation status |
| `make help` | Show this help message |

### Test Commands

| Command | Purpose |
|---------|---------|
| `make test` | Run all tests (AST + TAC) |
| `make test-ast` | Test AST generation only |
| `make test-tac` | Test TAC generation only |
| `make test-one TEST=file.c` | Test specific file |
| `make quick-test` | Quick test with test_case_1.c |

## Files Involved

### Source Files (You Create)
- `scanner.l` - Lexical analyzer definition (flex)
- `parser_new.y` - Parser grammar (bison)
- `main.cpp` - Main entry point
- `ast_new.cpp` - AST class implementations
- `ast_new.h` - AST class definitions
- `tac_str.cpp` - TAC string representations
- `tac_str.h` - TAC class definitions
- `tac_generator.cpp` - TAC generator singleton
- `tac_generator.h` - TAC generator header

### Generated Files (Created by Makefile)
- `parser.tab.c` - C code generated by bison
- `parser.tab.h` - Header generated by bison
- `lex.yy.c` - C code generated by flex

### Object Files (Created by g++)
- `main.o`
- `ast_new.o`
- `tac_str.o`
- `tac_generator.o`
- `parser.tab.o`
- `lex.yy.o`

### Executable
- `compiler` - Final compiled executable

## Makefile Variables

You can customize these at the top of the Makefile:

```makefile
# Compiler settings
CXX = g++           # C++ compiler
CXXFLAGS = ...      # Compilation flags
BISON = bison       # Bison command
FLEX = flex         # Flex command

# Files
SCANNER = scanner.l
PARSER = parser_new.y
MAIN_SRC = main.cpp
AST_SRC = ast_new.cpp
TAC_SRC = tac_str.cpp tac_generator.cpp

# Directories
TEST_DIR = .        # Where test files are
TEST_CASES = $(TEST_DIR)/test_case_*.c  # Test file pattern
```

## Compilation Process

The Makefile follows this process:

```
1. Parser Generation (bison)
   parser_new.y → parser.tab.c, parser.tab.h

2. Scanner Generation (flex)
   scanner.l → lex.yy.c

3. Compilation (g++)
   main.cpp → main.o
   ast_new.cpp → ast_new.o
   tac_str.cpp → tac_str.o
   tac_generator.cpp → tac_generator.o
   parser.tab.c → parser.tab.o
   lex.yy.c → lex.yy.o

4. Linking (g++)
   *.o files → compiler executable
```

## Testing Process

### Test Types

**test-ast**
- Runs compiler with `--show-ast` flag
- Generates AST for each test case
- Verifies AST structure

**test-tac**
- Runs compiler with `--show-tac` flag
- Generates TAC statements for each test case
- Verifies TAC generation

**test** (All tests)
- Runs both test-ast and test-tac

### Test Cases

The Makefile automatically discovers all files matching:
```
test_case_*.c
```

So if you have:
- test_case_1.c
- test_case_2.c
- test_case_5.c

All will be tested automatically with `make test`.

## Troubleshooting

### Compilation Fails with "parser_new.y not found"

**Error:** `parser_new.y: No such file or directory`

**Solution:** Make sure you have the refactored parser file in the directory.
```bash
ls parser_new.y
# Should exist. If not, check MIGRATION_GUIDE.md
```

### Compilation Fails with "ast_new.h not found"

**Error:** `ast_new.h: No such file or directory`

**Solution:** Ensure the new AST files are in the directory.
```bash
ls ast_new.*
# Should show ast_new.h and ast_new.cpp
```

### Bison/Flex not Found

**Error:** `bison: command not found` or `flex: command not found`

**Solution:** Install them.

On Ubuntu/Debian:
```bash
sudo apt-get install bison flex
```

On macOS:
```bash
brew install bison flex
```

### Make Syntax Error

**Error:** `Makefile:X: missing separator. Stop.`

**Solution:** Makefile uses tabs, not spaces. Use Tab key for indentation.

### Tests Don't Run

**Error:** `No test cases found`

**Solution:** Make sure you have test files.
```bash
ls test_case_*.c
# Should show at least one test file
```

## Advanced Usage

### Custom Compiler Flags

Edit the `CXXFLAGS` variable:

```makefile
# For debug symbols
CXXFLAGS = -std=c++11 -Wall -Wextra -g

# For optimization
CXXFLAGS = -std=c++11 -Wall -Wextra -O2

# For verbose output
CXXFLAGS = -std=c++11 -Wall -Wextra -v
```

### Custom Test Directory

If your test files are in a subdirectory:

```makefile
TEST_DIR = tests
TEST_CASES = $(TEST_DIR)/test_case_*.c
```

### Add More Tests

Just place your test files matching the pattern:
```bash
cp your_test.c test_case_13.c
make test
```
